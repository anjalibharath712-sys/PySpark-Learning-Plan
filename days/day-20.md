# Day 20: Validate and Present

## Goals
- Make the capstone reproducible, testable, and understandable to another developer.
- Review PySpark concepts and identify what to learn next.

## Practice
1. Run the capstone from a clean environment using only its documented setup steps.
2. Run tests and verify output schema, row counts, and quality checks.
3. Inspect the query plan and record important joins, exchanges, and partition choices.
4. Document data assumptions, limitations, and a next improvement.
5. Walk through the source, transformations, output, tests, and performance choices.

## Completion Checklist
- [ ] A new user can install dependencies and run the project.
- [ ] Input and output schemas are documented.
- [ ] Automated tests pass, including an edge case.
- [ ] Data-quality checks have clear outcomes.
- [ ] Output format and partitioning are justified.
- [ ] At least one performance choice is backed by a plan or measurement.

## Next Steps
Explore deployment on a managed Spark platform, cloud object storage, orchestration, advanced streaming, or deeper MLlib topics. Use the [official PySpark documentation](https://spark.apache.org/docs/latest/api/python/index.html) as your guide.
